# Philosophy

Dropkit contents is a factory output ledger, not a diary and not a magazine.

1. The file is the product. Smallest public unit = one **drop** (`src/content/posts/*.md`). If it is not in git, it did not ship.
2. Numbers, failures, and URLs beat adjectives.
3. Do not invent. Missing data is written as missing.
4. English is the public ledger. Other languages are restatements, not replacements.
5. Health gates (claims, trusted links, size) fail closed. Failed runs stay off `src/content/posts`.
6. Humans hold the kill switch. Merge/delete of the public site is not autonomous.
