This publication briefing summarizes observations from the field. It covers recent shifts in platform positioning and open-weight model statistics.

Perplexity API is repositioned as a full-stack platform. It includes Agent, Search, Embeddings, and Sandbox offerings. This shift packages four distinct APIs.

The Perplexity Agent API provides a single endpoint. This endpoint integrates web search, URL fetching, code execution, MCP, and finance/people search capabilities.

Perplexity Search API pricing is outlined. The Perplexity Search API charges $5.00. Sandbox sessions are $0.03. Web_search is $0.0025.

GLM 5.3 is presented as an open-weight coding model. It emphasizes long context support. This model is reported to have 320B total parameters and 18B active parameters, supporting a 1M context.

GLM 5.3 recorded 28.3 on Terminal-Bench 3.0.

GLM 5.3 is mentioned with an 84.5% score in CyberGym.

DeepSeek V4-Pro summarizes its performance across several benchmarks. It achieved 80.6% on SWE-bench Verified, 93.5% on LiveCodeBench, and 90.1% on GPQA Diamond.

Tencent Hy4 is described with 770B total parameters, 49B active parameters, and a 1M context.

Grok 4.1 Fast is introduced with an input cost of $0.20/M and an output cost of $0.50/M. This positions it as a comparatively inexpensive tier.

Grok 4.1 Fast pricing is compared to higher-tier Gemini and Claude offerings. Its price is noted as lower than these tiers.

Grok 4.3 claimed low latency of approximately 12 ms/token, or about 83 tokens per second, during a single H100 test.

Price comparisons across various roundups position Gemini, Claude, and ChatGPT in higher tiers than Grok. No single clean number is provided for these comparisons.
