# Public repository boundary

Only one repository is public:

| Repository | Responsibility | Start here |
| --- | --- | --- |
| [`dropkit.contents`](https://github.com/Hskim-droid/dropkit.contents) | Website, reviewed general-purpose skills, launched service introductions, selected notes | [README](../README.md) |

Kit code (`dropkits`) and earlier engines (`local-llm`) are private as of
2026-10-01. Their former project introductions and download links are retired.
Service source remains private; a public introduction and service URL are added
only after launch. No separate public skill repository is needed.

## Skill publication

Confirmed personal ownership and permission to share, reviewed generalization,
synthetic examples, an explicit license, and publication approval are required.
Employer-derived skills are not copied into this repository. Removing names or
rewriting a skill does not establish the right to publish it.

The build checks declared flags, registered paths, individually listed files,
symlinks, residual company/host strings, and unlisted download assets. These
checks enforce recorded decisions; they do not prove ownership or identify all
sensitive information. Human review precedes the public commit, not just build.

Private candidates must not be committed here even as drafts. Nightly RPA is a
new public instruction package with synthetic offline examples. Company-specific kits and internal reporting,
meeting and writing procedures remain outside the public sharing hub.

## Notes and history

Imports write into an explicitly configured owner-only private directory outside
this checkout. Public note sources require literal approved: true and draft:
false frontmatter; the build rejects other states. Rendering and feeds also use
those two conditions. CI cannot make a source file private once pushed.
Previously published news, media and project content was retired from current
source and build. Earlier public Git history and third-party copies remain.

The public repository contains no real ERP/QMS connector, browser cookie,
mail credential, customer dataset, or unattended production sender.
