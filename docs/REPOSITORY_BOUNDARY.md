# Public repository boundary

The public project is intentionally kept to two repositories with different jobs:

| Repository | Responsibility | Start here |
| --- | --- | --- |
| [`dropkit.contents`](https://github.com/Hskim-droid/dropkit.contents) | Publication shell, project introductions, public writing, and document content | [README](../README.md) |
| [`dropkits`](https://github.com/Hskim-droid/dropkits) | Skills for AI desktop apps: `SKILL.md` plus a deterministic Python renderer per kit | [README](https://github.com/Hskim-droid/dropkits#readme) · [releases](https://github.com/Hskim-droid/dropkits/releases/latest) |

On 2026-10-01 `dropkits` v1.0.0 became the public code repository. The earlier
`local-llm` repository is no longer public. This content hub keeps only
publication infrastructure and public material; kit code belongs in `dropkits`.

Neither public repository contains a real ERP/QMS connector, browser cookie,
mail credential, customer dataset, or unattended production sender.
